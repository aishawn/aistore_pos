## 近期已完成的 UI 改进

- 客户目录：窄屏卡片、清晰的编辑/删除入口、区分搜索无结果与暂无客户。
- 客户详情：手机端横向章节导航，补充返回目录入口；详情增加电话和客户代码；主题色统一。
- 客户新增/编辑：浅色内容区、手机章节导航、底部固定保存栏、错误显示在保存栏；取消初始自动聚焦以避免自动弹键盘。
- 客户余额/账单：窄屏卡片/账单行布局；明示本页合计；触控目标和焦点状态改善。
- 补货计划：统计层级、焦点状态和切换控件改善。
- 共用分页：触控按钮加大并补充键盘焦点提示。

## 建议交接顺序

1. **先核实生产版本**：确认 Dokploy 当前完成 SHA；若不是 `0f4ec04` 或后续 SHA，先确认部署状态，再做生产视觉核验。
2. **给本轮改动补视觉证据**：登录后检查客户列表、客户详情、客户新增/编辑、客户余额和账单预览，视口使用 390/768/1440px；不在验收中提交付款、删除客户或写入 Odoo。
3. **继续逐页打磨**：优先客户分组、供应商维护、采购/收货和库存列表；后续覆盖报表与设置。每轮只改明确发现的问题，运行 `npm run typecheck`、`npm run build`，推送后再按 SHA 留证。
4. **再做统一性复核**：抽查主题变量、标题层级、卡片/表格密度、44px 左右触控区、可见焦点、加载/空/错误态和打印样式。
