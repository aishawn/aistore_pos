# ADR-0001：以仓库维护功能事实与证据引用

日期：2026-11-03。状态：接受。依据：项目 owner 已批准本次实施方案；模块维护人待分配。

## 背景

设计、交接与 UAT 平铺，历史状态和不同版本证据难以比较。研发需要追溯，管理层需要可核实的能力、价值和限制。

## 决策

docs/project 是统一导航和功能视角摘要；设计/验证/进展按功能维护。原始证据、TEST_CATALOG 与 TEST_REPORT_INDEX 保留原职责。首期 AI 做完整样板，其他模块建立入口。

证据引用登记机器可读元数据，未知显式保留；发布准入仍按既有规则。报告从事实整理为有日期快照，不编辑历史证据凑齐当前状态。

## 备选与影响

不首先部署 Wiki 或观测平台：避免双事实源与额外运维。Markdown 对非技术读者的搜索体验有限，二期可加 MkDocs/VitePress。登记表带来少量维护成本，静态检查只防缺项和引用错误，仍需人工判断证据含义。
