# 模板入口

新增功能时复制[功能](feature.md)、[设计](design.md)、[验证](validation.md)、[进展](progress.md)为对应目录的 README.md / design.md / validation.md / progress.md。填写占位项后加入[功能清单](../features/README.md)。模板中的“待填写”不构成事实。

重要取舍复制[ADR](decision.md)；管理层汇报复制[报告](report.md)。测试 session 继续使用[现有模板](../../TEST_SESSION_TEMPLATE.md)，不要新建一套执行台账。检查器允许模板保留占位项，正式内容不应无依据标记已验证。
