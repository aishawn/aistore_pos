# 收银、退款与关班

更新日期：2026-11-09。负责人：POS owner 待指定。当前阶段：Orithos 原生销售候选已实现并通过本地后端回归；未部署、未进行线上业务写入；Odoo 仍是现行试点账本。

## 功能范围

购物车、报价、支付、票据、退款、现金与关班；物理 EFTPOS 与模拟卡支付分开验收。Odoo 退役前，所有新销售必须由 Orithos 门店账本受控写入；不得同时写两套账本。

## 当前实现与安全边界

- `POST /api/sales/checkout` 要求认证 vendor/outlet、幂等键、当前门店有效商品、服务端门店价和已配置税率；客户端价钱不能决定销售金额。
- 商品浏览、快捷键和客户搜索按认证 vendor/outlet 限定；客户、商品与收银机不得跨门店使用。
- Odoo-only 退役过滤只开放销售读取及受控 checkout；旧的任意销售创建/更新/作废入口保持退役。
- 库存流水与 checkout 幂等记录属于 Orithos 原生账本候选。当前数据和收银闭环尚未完成线上验收。

## 切换门槛

完成租户隔离、GST/支付/退款/关班/收货端到端验证，核对迁移差异并演练备份恢复后，才可对测试租户授权切换；之后逐店冻结旧账本、盘点并切换。不以页面可访问或单测通过代表 Odoo 已替换。
