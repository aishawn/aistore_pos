# 滞销与库存资金占用

更新日期：2026-11-03。功能 ID：CAP-AI-DEAD-STOCK。负责人：dead-stock 模块 owner 待指定。

## 目标与入口

帮助经营者发现长期未销售商品及可核实库存金额，优先人工处理。

技术类型：确定性数据分析，不依赖 LLM 计算金额。用户/接口入口：/api/odoo/dead-stock 与库存价值/滞销助手问法。

## 当前能力与状态

按门店读取 Odoo 当前库存、成本和已完成销售，计算 30/60/90 天无销售清单及有效成本子集金额；无效库存/成本单独列出。

已实现（主分支基线）；E-DEAD 为 71213472 历史线上只读记录；本基线未重新对账，也未证明释放现金。

## 验证与效果

E-DEAD 记录两店 HTTP 200、目录完整、零业务写入，Demo/SKR 无效成本或库存分别 8,360/8,262 行，金额只覆盖有效子集。本期不把历史占用金额做成管理层收益 KPI；E-COST-CONFLICT 与其他审计的公司标签/成本口径冲突尚待核对。
