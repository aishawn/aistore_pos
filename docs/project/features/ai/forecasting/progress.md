# 销量预测与补货：进展与问题

更新日期：2026-11-04。负责人待分配，优先级 P0 为发布/数据安全阻断，P1 为功能质量，P2 为效果增强。

## 已完成

只读销售/库存采集、每日快照、Python 多候选模型、逐商品选模、滚动/分群回测、风险与建议、紧急风险筛选均有实现。只读快照与模拟成本不能作为真实缺货或经营收益。

验证范围：已实现（主分支基线）；E-RO / E-URGENT 有旧 runtime 线上只读验证；E-FC730 为研究回测，生产模型质量与自动采购准入未通过。

2026-11-04 已优化分群离线评测器显式模型路径，完整重跑 2,000 SKU、365 天、7/14/28 天及六模型，和既有分群报告逐字段一致。该优化只减少评测器开销，不改变预测策略。营业日评估已对 19 个 owner-confirmed 闭店日使用版本化日历；生产 forecast engine 仍不读取营业日历。详见[复跑 session](../../../../test-sessions/2026-11-04-forecast-evaluator-fast-path.md)和[分群报告](../../../../UAT_AI_FORECAST_SEGMENTED_2000SKU_2026-11-04.md)。

## 验证闭环

问题状态默认为 OPEN。先确定输入与复现证据，再冻结修复 SHA，补负向回归并做适用环境验收；缺 runtime/真实数据时只关闭源码或 fixture 子问题。当前事实依据见[validation](validation.md)。

## 迭代策略

先修数据与安全，再改功能正确性，最后按固定对照比较体验、延迟、成本和经营结果。每次更新本页及[测试索引](../../../../TEST_REPORT_INDEX.md)；需要架构取舍时新增 ADR。禁止为了改变状态文字而重写历史证据。
