# 销量预测与补货

更新日期：2026-11-03。功能 ID：CAP-AI-FORECAST。负责人：forecasting 模块 owner 待指定。

## 目标与入口

识别未来供需风险，给出带原因、置信度和数据缺口的补货审阅清单。

技术类型：统计时序预测 + 规则决策 + 数据质量门禁。用户/接口入口：/stock/replenishment；/api/ai/forecast/sales、/risks；/api/ai/decisions/replenishment/preview。

## 当前能力与状态

只读销售/库存采集、每日快照、Python 多候选模型、逐商品选模、滚动/分群回测、风险与建议、紧急风险筛选均有实现。只读快照与模拟成本不能作为真实缺货或经营收益。

已实现（主分支基线）；E-RO / E-URGENT 有旧 runtime 线上只读验证；E-FC730 为研究回测，生产模型质量与自动采购准入未通过。

## 验证与效果

E-FC730：730 天、500 个高销量商品，7/14/28 天回测，间歇需求 TSB 相对基线改善 11.6%/11.3%/10.3%，但 WAPE 为 1.404/1.408/1.442，全部绝对门失败。研究未接可信缺货、原生库存、交期和实际采购成本。E-RO 原生快照仅 Demo 2 天、SKR 3 天，交期覆盖均为 0%。E-URGENT 已记录风险筛选 UI 的历史部署验证，但不开放自动采购。
