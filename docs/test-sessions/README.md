# Test Sessions

Store one dated report per meaningful test session in this directory.

Use the parent template:

```text
docs/TEST_SESSION_TEMPLATE.md
```

Recommended filename:

```text
YYYY-MM-DD-short-slug.md
```

After completing a session, add its summary to:

```text
docs/TEST_REPORT_INDEX.md
```

Raw `UAT_*.json` files and screenshots remain separate evidence artifacts. Do not paste secrets or large logs into session reports.
