# 分群需求模型回测明细（2026-11-05）

## 范围与口径

数据源是 `skr-sales-snapshot-365d.json`，使用 `ai_forecast_walkforward_eval.py` 的 sales-only walk-forward 结果。覆盖 2,000 个 SKU、7/14/28 天预测窗；闭店日使用店主确认的营业日历屏蔽。库存截尾、真实 fill rate、采购成本和经营收益不在本次 sales-only 结果中。

`skuCoverage = scoredProducts / expectedSkuCount`。`horizonTotalWape` 是预测窗累计销量 WAPE；`biasRatio` 为系统性高估/低估方向；`mase` 以序列基准衡量；`p80Coverage`/`p90Coverage` 是区间覆盖率；`wapeStdDev` 和 `wapeCv` 衡量折间稳定性。空 MASE 表示该分群没有可定义的尺度基准，不是 0。

## 结论与门禁

- SKU coverage 达到 100%，但绝对误差门槛 `WAPE <= 30%` 在所有分群和 horizon 均未通过；REGULAR 28 天最接近但仍为 35.8%。
- SPARSE 是主要风险群，selected WAPE 为 93.1%-128.5%；不能仅凭较高 P80/P90 覆盖率宣称准确，因为区间可能过宽。
- 相对 Seasonal Naive 的改善在 INTERMITTENT 和 SPARSE 的部分 horizon 明显，但不抵消绝对 WAPE、冷启动 Bias 和缺失库存标签。
- 当前结果只支持研究和人工审核建议，不支持修改生产默认模型、自动补货或写回 Odoo。安全违规为 0，但库存、成本和 fill-rate 仍未测得。
