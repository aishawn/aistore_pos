# 客户试用限制（2026-10-29）

当前 Demo 使用共享 `aipos_uat`。试用数据不是独立客户生产数据，管理员必须保留紧急停用和恢复权限。

- 仅开放指定商品和少量交易；每日核对销售、GST、库存和现金关班。
- 暂不把批量改价、库存调整、采购收货和管理员权限作为客户自助能力。
- AI 普通问答受应用配额保护；图片/发票 OCR 受 provider 配额影响，暂不承诺可用性或准确率。
- 打印机、钱箱、扫码器和 EFTPOS 尚未完成现场验收；未连接设备必须按不可用处理。
- 离线 POS 未完成验收，试用说明按“暂不支持”处理。
- 正式生产放行前仍需独立租户/数据库、跨租户越权测试、备份恢复后的登录和完整 Odoo 业务对账。
