## 当前问题与风险

1. **部署证据断链**：`7544d03` 已被用户确认部署，但尚未从 Dokploy 控制台证明实际运行的前后端容器就是该 SHA；旧镜像或缓存仍可能导致源码与线上不一致。
2. **动态页面缓存风险**：`7544d03` 的目的就是修复 live status page 的旧缓存。必须在控制台和公网响应头同时确认动态页面使用 `no-store/private` 或等价策略；仅返回 HTTP 200 不足以证明修复生效。
3. **AI 能力边界**：生产 AI 当前关闭，不能将禁用态回归写成 AI 功能通过。
4. **支付能力边界**：模拟 Card 收款不能替代实体终端、终端断网、退款到原卡或对账验收。
5. **测试数据风险**：后续真实写入只能使用一次性隔离租户；禁止向生产 Demo 公司写销售、退款、采购、库存、现金或关班数据。
6. **工作区风险**：当前存在大量 UAT JSON、截图和用户已有改动；禁止 `git add -A`，提交时只选择明确属于本交接文档的文件。
