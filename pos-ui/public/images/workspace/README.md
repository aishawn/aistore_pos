# Workspace dashboard artwork

Original decorative images generated on 2026-10-24 using the `website-images`
skill and ModKie. The service returned provider `kie`, model
`gpt-image-2-text-to-image` for all nine images.

- `background.webp`: cool blue-gray canvas with champagne glass ribbons; 1920px wide.
- `summary.webp`: milky white and apricot ascending glass columns.
- `sell.webp`, `insights.webp`, `stock.webp`, `purchasing.webp`, `customers.webp`,
  `permissions.webp`, `ai.webp`: matching pastel frosted-glass module illustrations.

Section images are 640px wide. All images are WebP, with no generated labels or
branding. Text, functional icons, and links are rendered by the application.
The illustrations are decorative and do not represent live business metrics.
